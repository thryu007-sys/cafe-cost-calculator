# ☕ 카페 원가계산기 PRO (Cafe Menu Cost & BEP Calculator SaaS)

실제 1인 카페 및 소상공인 사장님을 위한 **1잔 실질 원가, 배달 마진, 손익분기점(BEP) 분석 및 수익화 결제 시스템 완비 웹 애플리케이션**입니다.

---

## 💎 비즈니스 수익화 모델 (Monetization Architecture)

본 프로그램은 **Freemium(부분 유료화) SaaS 모델**로 설계되어 있어, 무료 유저를 유입시키고 프리미엄 PRO 기능으로 유료 결제를 유도합니다.

| 구분 | 베이직 (FREE 무료 회원) | PRO 사장님 멤버십 (유료) |
| :--- | :--- | :--- |
| **기본 원가 계산** | 기본 음료 원가, 포장재 자동 적용 | 기본 원가 + 정밀 분석 무제한 |
| **메뉴 저장 한도** | 1개 메뉴만 저장 가능 | **전 메뉴 레시피 무제한 저장 & 비교** |
| **손익분기점(BEP) 진단**| 🔒 잠금 (PRO 전용) | **월/일 손익분기 판매잔수 실시간 계산** |
| **배달앱 실마진 분석** | 🔒 잠금 (PRO 전용) | **배민·쿠팡이츠·요기요 수수료 공제 후 실마진 비교** |
| **엑셀(CSV) 다운로드** | 🔒 잠금 (PRO 전용) | **원가 명세서 엑셀 파일 즉시 다운로드** |
| **A4 보고서 인쇄** | 🔒 잠금 (PRO 전용) | **공식 A4 영수증·보고서 인쇄 및 PDF 저장** |
| **요금제** | 평생 무료 | **평생 소장권 29,900원 / 월간 구독 9,900원** |

## 💳 결제 시스템 (Payment Gateway) 연동 완료

* **국내 대표 PG사 연동 지원**:
  * **토스페이먼츠 (Toss Payments)** & **포트원 (PortOne)** 결제 SDK 탑재
  * **카카오페이**, **토스페이**, **네이버페이**, **국내 모든 신용/체크카드** 지원
* **즉시 승인 & 라이선스 키 자동 발급**:
  * 결제 완료 즉시 고유한 라이선스 키(`CAFE-PRO-XXXX-XXXX`)가 발급되며 모든 PRO 기능이 실시간 잠금 해제됩니다.
  * 기기를 바꾸거나 다른 컴퓨터에서 접속해도 발급된 라이선스 키만 입력하면 즉시 복원됩니다.
* **상용 결제 전환 기능**:
  * [설정/결제] 메뉴에서 사장님 본인의 상점 클라이언트 키(Client Key)만 입력하면 실제 매출이 정산되는 상용 결제 모드로 즉시 전환됩니다.
