# ☕ 카페 메뉴 원가계산기 (Cafe Menu Cost Calculator)

실제 1인 카페 및 소상공인 사장님을 위한 **1잔 진짜 원가, 마진율, 포장재 자동 계산 웹 애플리케이션**입니다.

---

## 📌 주요 특징 및 기능

1. **① 메뉴명 직관적 입력**:
   - 불필요한 드롭다운 없이 수기 입력창 하나로 메뉴명을 입력합니다.
2. **② & ③ 온도 및 이용 형태 원클릭 토글**:
   - `HOT / ICE`, `매장 / 테이크아웃` 선택에 따라 포장재가 자동 적용됩니다.
3. **④ Coffee702 매장 운영 포장재 자동 적용**:
   - **매장 + HOT**: 0원 (모두 제외)
   - **매장 + ICE**: 20원 (빨대만 포함)
   - **테이크아웃 + HOT**: 179원 (컵 48.9 + 뚜껑 50 + 홀더 30 + 캐리어 50)
   - **테이크아웃 + ICE**: 199원 (컵 48.9 + 뚜껑 50 + 홀더 30 + 빨대 20 + 캐리어 50)
   - 모든 단가·수량 입력창에 천 단위 콤마(`,`) 실시간 서식 지원.
4. **⑤ 음료 재료비 관리**:
   - 원두, 우유, 시럽 등 재료별 구입가격, 규격, 1잔 사용량을 입력하여 실시간 원가를 산출합니다.
5. **⑥ 변동비 및 카드 수수료**:
   - 결제수수료율, 배달플랫폼 수수료, 기타 변동비를 1잔당 비용에 정확히 반영합니다.
6. **⑦ 월 고정비 & 인건비 관리 (선택적 1잔 배분)**:
   - **월 매장 고정비**: 임대료(700,000원) + 관리비·공과금(70,000원) + 인터넷·보험(50,000원) = 820,000원
   - **월 인건비**: 급여(4,000,000원) = 4,000,000원
   - **월 총액**: 4,820,000원
   - **월 판매 잔수 (선택 사항)**:
     - 비워두거나 0 입력 시: 1잔 직접원가(재료+포장+변동비)만으로 깔끔하게 계산.
     - 판매 잔수 입력 시 (예: 3,000잔): 고정비·인건비가 1잔당 정확히 분할 배분(1,607원)되어 최종 원가에 포함.
7. **⑨ 최종 원가 13가지 명세 및 KPI 요약**:
   - 메뉴명, 온도, 이용형태, 재료비, 포장비, 변동비, 수수료, 배부원가, 최종원가, 판매가, 마진, 원가율, 이익률 명시.
8. **데이터 보존 & 백업**:
   - 메뉴 저장 스냅샷, JSON 내보내기/가져오기 기능 제공.

## 💻 로컬(내 컴퓨터)에서 실행하는 방법

1. **서버 실행**:
   터미널(PowerShell 또는 명령 프롬프트)에서 해당 폴더로 이동 후 아래 명령어를 실행합니다.
   ```bash
   python server.py
   ```
2. **브라우저 접속**:
   크롬, 엣지, 웨일 등 웹 브라우저를 열고 아래 주소로 접속합니다.
   ```
   http://localhost:8080
   ```

## 🚀 GitHub 및 Render 무료 배포 가이드 (초보자용)

웹 브라우저만으로 3분 만에 인터넷 어디서든 접속할 수 있는 무료 웹사이트로 배포할 수 있습니다.

### 1단계: GitHub에 코드 올리기 (웹에서 드래그 앤 드롭)
1. [GitHub](https://github.com)에 로그인합니다.
2. 우측 상단의 `+` 버튼 클릭 &rarr; **`New repository`** 선택.
3. `Repository name`에 `cafe-cost-calculator` 입력 &rarr; **`Create repository`** 클릭.
4. 새로 열린 페이지에서 **`uploading an existing file`** 링크 클릭.
5. 본 프로젝트 폴더 안의 모든 파일(`index.html`, `styles.css`, `app.js`, `server.py`, `README.md`, `src/` 폴더)을 브라우저 화면으로 드래그 앤 드롭합니다.
6. 하단의 **`Commit changes`** 버튼을 누르면 업로드가 완료됩니다.

### 2단계: Render.com에서 무료 웹사이트로 띄우기
1. [Render.com](https://render.com)에 무료 회원가입 후 로그인합니다. (GitHub 계정으로 간편 로그인 가능)
2. 대시보드 우측 상단의 **`New +`** 클릭 &rarr; **`Static Site`** 선택.
3. 방금 만든 `cafe-cost-calculator` 저장소를 연결(`Connect`)합니다.
4. 설정값 확인:
   - **Name**: `my-cafe-calculator` (원하는 이름 입력)
   - **Branch**: `main`
   - **Build Command**: 비워둠 (Static 웹앱이므로 필요 없음)
   - **Publish Directory**: `.` (점 하나만 입력)
5. 하단의 **`Create Static Site`** 클릭!
6. 약 1분 후 `https://my-cafe-calculator.onrender.com` 과 같은 고유한 인터넷 주소가 생성되며, 스마트폰이나 태블릿에서도 바로 사용할 수 있습니다!
